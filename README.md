# Painel de LED · Aeroporto (960×480 · 15 s)

Página para aprovação dos vídeos do painel em loop. Abra `index.html` (ou o link do GitHub Pages).

Para adicionar novos vídeos: solte o render `.mp4` na pasta `Render` e rode `bash atualizar.sh` no Git Bash — ele converte para web, atualiza `videos.js` e publica.
